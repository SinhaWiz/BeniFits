# BeniFits

Fullstack web project starter with a React frontend and an Express backend.

## Structure

- `client/` - React app powered by Vite
- `server/` - Express API

## Scripts

From the repository root:

- `npm run dev:client` - start the React app
- `npm run dev:server` - start the API server
- `npm run build:client` - build the React app
- `npm run start:server` - start the API server in production mode

## Next steps

1. Install dependencies in `client/` and `server/`.
2. Create your backend routes and data models.
3. Connect the React app to the API.
